# MTBench environments

TSIL uses MTBench for Isaac Gym environments and assets. Training and evaluation
are implemented in the top-level `core/` and `projects/TSIL/` directories.

- `assets/`: robot, object and scene assets.
- `isaacgymenvs/tasks/`: environment definitions.
- `isaacgymenvs/cfg/task/`: environment settings.
- `isaacgymenvs/utils/`: environment utilities.

See the [TSIL README](../README.md) for installation and usage.

Upstream project: https://github.com/Viraj-Joshi/MTBench
